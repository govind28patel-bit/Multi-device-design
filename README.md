# Multi-Device Design: Me4U

UX case study by **Govind Patel**: designing Mahindra's Me4U connected-car experience across phone, smartwatch and car display for the XEV electric SUVs.

The site covers context, research (competitive audit, owner interviews, key insights), the problem, an interactive two-scenario service blueprint, user flow, both user journeys with screens, and the design system.
